# 🎥 YouTube Home Page Clone

YouTube Home Page Clone is a static replica of the original YouTube homepage, built to practice and showcase my HTML and CSS skills. This project focuses on creating a layout similar to the YouTube homepage, including key elements such as navigation, footer, and video thumbnails.

## ✨ Features
Navigation Bar: Mimics the YouTube top navigation, with links and icons.<br>
Video Thumbnails: Displays a few video thumbnails as seen on the homepage.<br>
Footer Section: Includes a footer just like the original page.

## 🚀 Technologies Used
HTML5<br>
CSS3

## 📄 How It Works
Visit the page to see a design similar to YouTube’s homepage.<br>
Explore the navigation bar, video section, and footer elements.<br>
No functionality—just a clean, static layout to practice web design skills.<br>
This project helped me refine my HTML and CSS abilities while recreating a familiar and widely-recognized layout. <hr>
